title: "GET /v1/vaults/:profile — Vault State"
sidebarTitle: "Vault State"
description: "GET /v1/vaults/:profile returns a trader vault's current NAV, AUM, shares, high-water mark, fee rates, and deposit status. No authentication required."
---

The vault state endpoint exposes the complete on-chain snapshot of a single trader vault. You can use it to display live NAV, monitor assets under management, check whether deposits are currently open, inspect the fee structure, and verify the vault's Arcadia score tier — all without authentication. Poll this endpoint to power vault detail pages, capacity gauges, or automated deposit eligibility checks.

<Note>
  **NAV per share scaling:** `nav_per_share` is expressed in USDC units, meaning
  the raw on-chain value has already been divided by 1,000,000. A value of
  `11.25` means each vault share is currently worth $11.25 USDC.

  **Performance fee in basis points:** `perf_fee_bps` is expressed in basis
  points where 100 bps = 1%. A value of `1500` means the trader earns a 15%
  performance fee on profits above the high-water mark. This fee is only charged
  on gains — it is never deducted from your principal.
</Note>

## Request

### Path Parameters

<ParamField path="profile" type="string" required>
  The base58-encoded public key of the trader's vault profile PDA. You can
  obtain this value from the leaderboard response or from the `profile` field
  in any investor position.
</ParamField>

---

## Response

<ResponseField name="nav_per_share" type="number">
  Current net asset value per share in USDC. Reflects the vault's total assets
  divided by total outstanding shares after fees.
</ResponseField>

<ResponseField name="total_shares" type="number">
  Total number of shares outstanding across all investors and the trader
  themselves.
</ResponseField>

<ResponseField name="aum" type="number">
  Assets under management in USDC — the total USD value of all capital
  currently deployed or held in the vault.
</ResponseField>

<ResponseField name="hwm" type="number">
  High-water mark NAV per share in USDC. Performance fees are only charged on
  gains above this level, protecting investors from paying fees on recovered
  losses.
</ResponseField>

<ResponseField name="status" type="string">
  Current operational status of the vault. One of:
  - `"active"` — vault is trading and accepting deposits (if `deposits_open` is `true`)
  - `"paused"` — trading is temporarily halted; no new deposits accepted
  - `"closed"` — vault has been wound down; withdrawals only
</ResponseField>

<ResponseField name="capacity_usd" type="number">
  Maximum AUM the vault is configured to accept in USDC. Deposits that would
  push AUM above this value are rejected.
</ResponseField>

<ResponseField name="trader_shares" type="number">
  The number of shares held by the trader themselves. Represents the trader's
  own capital at risk ("skin in the game").
</ResponseField>

<ResponseField name="deposits_open" type="boolean">
  `true` if the vault is currently accepting new investor deposits. `false`
  when the vault is at capacity, paused, or closed.
</ResponseField>

<ResponseField name="trader_claimable" type="number">
  Accumulated performance and management fees in USDC that the trader has
  earned but not yet claimed from the vault.
</ResponseField>

<ResponseField name="base_mint" type="string">
  The base58 public key of the SPL token mint used as the vault's settlement
  currency (USDC on mainnet).
</ResponseField>

<ResponseField name="vault_token" type="string">
  The base58 public key of the vault's share token mint. Investors receive
  these tokens as proof of their deposit.
</ResponseField>

<ResponseField name="perf_fee_bps" type="number">
  Performance fee rate in basis points (100 bps = 1%). Charged on profits
  above the high-water mark only.
</ResponseField>

<ResponseField name="mgmt_fee_bps" type="number">
  Annual management fee rate in basis points. Accrues continuously and is
  deducted from NAV regardless of performance.
</ResponseField>

<ResponseField name="score_tier" type="string">
  The Arcadia score tier assigned to this vault based on its verified
  performance history. Examples: `"Bronze"`, `"Silver"`, `"Gold"`,
  `"Platinum"`.
</ResponseField>

## Example Request

```bash
curl -X GET "https://api.arcadia.trade/v1/vaults/BzHQpBRU5e2ZVPxq8dCRcHqMdVoP5kR7fLnW2aJtG4xY"
```
