---
title: "GET /v1/vaults/:profile/trades — Trade History"
sidebarTitle: "Trade History"
description: "GET /v1/vaults/:profile/trades returns paginated closed trade history for a vault, including PnL, leverage, direction, and liquidation status."
---

The trade history endpoint surfaces every closed position a vault has executed, giving you a granular view of the trader's strategy in action. Each record includes the market traded, position direction, size, leverage, entry and exit prices, realised PnL net of fees, and whether the position was liquidated. This data powers the trade log on vault detail pages and can be used to audit a trader's edge before committing capital. Paginate backward through history using the `before` cursor.

## Request

### Path Parameters

<ParamField path="profile" type="string" required>
  The base58-encoded public key of the trader's vault profile PDA.
</ParamField>

### Query Parameters

<ParamField query="limit" type="number" default="50">
  Number of trade records to return per page. Accepted range is `1` to `200`.
  Requests exceeding `200` are clamped to `200`.
</ParamField>

<ParamField query="before" type="number">
  Cursor timestamp (Unix seconds). When provided, only trades with a
  `closed_at` value strictly less than this timestamp are returned. Use the
  `closed_at` of the oldest record in the current page to fetch the next page.
</ParamField>

---

## Response

The response is an array of `TradeRecord` objects ordered from most recently closed to oldest.

<ResponseField name="id" type="string">
  A unique identifier for this trade record, generated by the Arcadia indexer.
</ResponseField>

<ResponseField name="market" type="string">
  The market symbol traded, e.g. `"XAU/USD"`, `"EUR/USD"`, `"BTC/USD"`.
</ResponseField>

<ResponseField name="direction" type="string">
  Position direction: `"long"` or `"short"`.
</ResponseField>

<ResponseField name="size_usd" type="number">
  Notional position size in USDC at entry, before leverage.
</ResponseField>

<ResponseField name="leverage" type="number">
  Leverage multiplier applied to this position (e.g. `5` = 5×).
</ResponseField>

<ResponseField name="entry_px" type="number">
  The price at which the position was opened.
</ResponseField>

<ResponseField name="exit_px" type="number">
  The price at which the position was closed or liquidated.
</ResponseField>

<ResponseField name="realized_pnl" type="number">
  Realised profit or loss in USDC after trading fees. Negative values indicate
  a loss on this trade.
</ResponseField>

<ResponseField name="fees_usd" type="number">
  Total trading fees paid for this position in USDC, including open and close
  fees.
</ResponseField>

<ResponseField name="was_liquidated" type="boolean">
  `true` if this position was force-closed by the protocol due to insufficient
  margin. `false` for trades closed voluntarily by the trader.
</ResponseField>

<ResponseField name="opened_at" type="number">
  Unix timestamp (seconds) when the position was opened on-chain.
</ResponseField>

<ResponseField name="closed_at" type="number">
  Unix timestamp (seconds) when the position was closed or liquidated on-chain.
  Use this value as the `before` cursor to paginate to the next page.
</ResponseField>

<ResponseField name="sig" type="string">
  The Solana transaction signature for the closing transaction of this trade.
  Can be verified on any Solana explorer.
</ResponseField>

---

## Example Request

```bash
curl -X GET "https://api.arcadia.trade/v1/vaults/BzHQpBRU5e2ZVPxq8dCRcHqMdVoP5kR7fLnW2aJtG4xY/trades?limit=3"
```

**Fetching the next page** using the `before` cursor:

```bash
curl -X GET "https://api.arcadia.trade/v1/vaults/BzHQpBRU5e2ZVPxq8dCRcHqMdVoP5kR7fLnW2aJtG4xY/trades?limit=3&before=1715260800"
```
