The portfolio endpoint gives you a real-time financial snapshot of every active vault position you hold. Unlike the raw account endpoint, each item here is enriched with the vault's current net asset value so you can see your position's live USD value, the profit or loss relative to your cost basis, and your percentage return — all in a single request. Use this endpoint to build portfolio dashboards, calculate exposure, or surface performance data to your users.

## Request

### Path Parameters

<ParamField path="wallet" type="string" required>
  The base58-encoded Solana wallet address of the investor. The JWT supplied in
  the `Authorization` header must match this wallet; mismatches return
  `403 Forbidden`.
</ParamField>

### Headers

<ParamField header="Authorization" type="string" required>
  A valid Bearer JWT issued for the wallet address in the path. Format:
  `Bearer <jwt>`.
</ParamField>

---

## Response

The response is an array of `PortfolioItem` objects — one for each vault in which the investor holds a non-zero share balance.

<ResponseField name="profile" type="string">
  The base58 public key of the trader's vault profile PDA.
</ResponseField>

<ResponseField name="trader_handle" type="string">
  The human-readable handle registered by the trader for this vault.
</ResponseField>

<ResponseField name="shares" type="number">
  The number of vault shares currently held in this position.
</ResponseField>

<ResponseField name="value_usd" type="number">
  The current USD value of the position, calculated as `shares × nav_per_share`
  using the vault's most recently computed NAV. Amounts are in USDC units (raw
  on-chain value divided by 1,000,000).
</ResponseField>

<ResponseField name="cost_basis_usd" type="number">
  Total USD deposited into this position, adjusted for prior partial
  withdrawals. Serves as the baseline for PnL calculations.
</ResponseField>

<ResponseField name="pnl_usd" type="number">
  Unrealised profit or loss in USD, computed as `value_usd - cost_basis_usd`.
  Negative values indicate a loss relative to cost basis.
</ResponseField>

<ResponseField name="roi_pct" type="number">
  Percentage return on this position, expressed as a decimal percentage (e.g.
  `12.5` means 12.5%). Calculated as `(pnl_usd / cost_basis_usd) × 100`.
</ResponseField>
