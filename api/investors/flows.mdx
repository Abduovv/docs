The flows endpoint returns a chronological record of every capital movement tied to your investor account — both deposits into vaults and withdrawals from them. Each event captures the exact NAV per share at the time of execution, the number of shares exchanged, and the USD amount, giving you a complete audit trail for tax reporting, reconciliation, or performance attribution. Events are returned newest-first by default.

## Request

### Path Parameters

<ParamField path="wallet" type="string" required>
  The base58-encoded Solana wallet address of the investor. The JWT in the `Authorization` header must match this wallet; mismatches return `403 Forbidden`.
</ParamField>

### Query Parameters

<ParamField query="limit" default="200" type="number">
  Maximum number of flow events to return. Accepted range is `1` to `1000`. Requests exceeding `1000` are clamped to `1000`.
</ParamField>

### Headers

<ParamField header="Authorization" type="string" required>
  A valid Bearer JWT issued for the wallet address in the path. Format: `Bearer <jwt>`.
</ParamField>

---

## Response

The response is an array of flow event objects ordered from most recent to oldest. Each object represents a single on-chain deposit or withdrawal settlement.

<ResponseField name="type" type="string">
  The direction of the capital movement. Either `"deposit"` (capital flowing into a vault) or `"withdraw"` (capital flowing back to the investor).
</ResponseField>

<ResponseField name="profile" type="string">
  The base58 public key of the vault profile PDA this flow event belongs to.
</ResponseField>

<ResponseField name="trader_handle" type="string">
  The human-readable handle of the trader who manages the vault.
</ResponseField>

<ResponseField name="amount_usd" type="number">
  The USDC value of the deposit or withdrawal at the time of execution, as a raw `u64` scaled by 1,000,000 (divide by 1,000,000 for USDC).
</ResponseField>

<ResponseField name="shares" type="number">
  The number of vault shares minted (on deposit) or burned (on withdrawal) as a result of this flow event, as a raw `u64` scaled by 1,000,000.
</ResponseField>

<ResponseField name="nav_per_share" type="number">
  The vault's NAV per share at the moment the transaction was settled on-chain, as a raw `u64` scaled by 1,000,000. Use this together with `shares` to verify `amount_usd`.
</ResponseField>

<ResponseField name="ts" type="number">
  Unix timestamp (seconds) of when the flow was confirmed on-chain.
</ResponseField>

## Related: Notifications

`GET /v1/investors/:wallet/notifications` provides a real-time feed of account-level events — deposit confirmations, withdrawal readiness alerts, and vault status changes. It shares the same Bearer JWT authentication requirement as this endpoint. Refer to the Notifications reference for full details.
