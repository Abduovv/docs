The `/v1/traders` endpoint gives you a paginated snapshot of every trader on Arcadia, complete with their Arcadia Score, performance tier, current assets under management, recent returns, and risk metrics. Use it to build leaderboards, power investor discovery flows, or filter for vaults that match a specific risk profile. All fields reflect the most recently computed on-chain state — scores and metrics update continuously as new trades settle.

## Request

```
GET https://api.arcadia.trade/v1/traders
```

### Query Parameters

<ParamField query="limit" type="number" default="50">
  Maximum number of traders to return per page. Cannot exceed `100`.
</ParamField>

<ParamField query="offset" type="number" default="0">
  Number of records to skip before returning results. Use with `limit` to paginate through the full trader list.
</ParamField>

## Response

Returns an array of `TraderListItem` objects.

<ResponseField name="handle" type="string" required>
  The trader's unique display name on Arcadia.
</ResponseField>

<ResponseField name="wallet" type="string" required>
  The trader's Solana wallet address in base58 encoding.
</ResponseField>

<ResponseField name="profile" type="string" required>
  The on-chain program-derived address (PDA) of the trader's Arcadia profile account, in base58 encoding.
</ResponseField>

<ResponseField name="score" type="number" required>
  The trader's current Arcadia Score on a scale of 0–1000. Higher scores indicate stronger risk-adjusted performance with greater statistical confidence.
</ResponseField>

<ResponseField name="tier" type="string" required>
  Performance tier derived from the Arcadia Score. One of `Verified`, `Established`, `Advanced`, `Elite`, or `Apex`.
</ResponseField>

<ResponseField name="confidence" type="string" required>
  Statistical confidence in the current score based on trade count and history length. One of `low`, `med`, or `high`.
</ResponseField>

<ResponseField name="capacity_usd" type="number" required>
  Maximum investor capital, in USDC (6 decimal places), that this vault is configured to accept.
</ResponseField>

<ResponseField name="aum" type="number" required>
  Current assets under management in USDC (6 decimal places), including both investor deposits and the trader's own capital.
</ResponseField>

<ResponseField name="return_30d" type="number" required>
  Vault return over the trailing 30 days, expressed as a percentage (e.g. `14.72` means +14.72%).
</ResponseField>

<ResponseField name="max_dd" type="number" required>
  Maximum drawdown over the vault's full history, expressed as a percentage. Lower is better.
</ResponseField>

<ResponseField name="sortino" type="number" required>
  Sortino ratio computed over the trailing 90 days. Measures return per unit of downside risk.
</ResponseField>

<ResponseField name="deposits_open" type="boolean" required>
  `true` if the vault is currently accepting new investor deposits; `false` if it is closed to new capital.
</ResponseField>

<ResponseField name="style_tags" type="string[]" required>
  Array of trading style labels assigned to the trader, such as `"trend-following"`, `"scalper"`, or `"mean-reversion"`.
</ResponseField>

<ResponseField name="trader_self_funded" type="number" required>
  Amount of the trader's own capital currently deployed in the vault, in USDC (6 decimal places). A higher self-funded amount indicates greater skin in the game.
</ResponseField>

<ResponseField name="agent" type="string">
  Optional identifier for the automated agent or bot framework operating this vault, if any. Omitted when the trader is human-operated.
</ResponseField>

<ResponseField name="style" type="string">
  Optional free-text style descriptor provided by the trader. Distinct from `style_tags`, which are system-assigned labels.
</ResponseField>

## Example

### cURL

```bash
curl -G https://api.arcadia.trade/v1/traders \
  --data-urlencode "limit=3" \
  --data-urlencode "offset=0"
```
