The `/v1/traders/:handle/score-history` endpoint returns a time-ordered series of Arcadia Score snapshots for a given trader. Scores are computed continuously as new trades settle on-chain — this endpoint surfaces the daily snapshot values so you can plot a trader's score trajectory, detect sustained improvement, or identify periods of degraded performance. It is particularly useful for distinguishing traders whose high scores reflect durable consistency from those who peaked recently on a small number of trades.

## Request

```
GET https://api.arcadia.trade/v1/traders/:handle/score-history
```

### Path Parameters

<ParamField path="handle" type="string" required>
  The trader's unique Arcadia handle. Handles are case-insensitive.
</ParamField>

### Query Parameters

<ParamField query="days" type="number" default="180">
  Number of calendar days of history to return, counting back from today. Maximum value is `730` (two years).
</ParamField>

## Response

Returns an array of `ScorePoint` objects, ordered from oldest to newest.

<ResponseField name="ts" type="number" required>
  Unix timestamp (seconds) for this snapshot, snapped to midnight UTC on the day the score was recorded.
</ResponseField>

<ResponseField name="score" type="number" required>
  The trader's Arcadia Score at the time of this snapshot, on a scale of 0–1000.
</ResponseField>

## Example

### cURL

```bash
curl -G https://api.arcadia.trade/v1/traders/apex_trader/score-history \
  --data-urlencode "days=45"
```

### Response

```json
[
  { "ts": 1714435200, "score": 821 },
  { "ts": 1715040000, "score": 839 },
  { "ts": 1715644800, "score": 856 },
  { "ts": 1716249600, "score": 871 },
  { "ts": 1716854400, "score": 883 },
  { "ts": 1717459200, "score": 899 },
  { "ts": 1718064000, "score": 962 }
]
```

<Tip>
  A rising score trend combined with a `confidence` of `"high"` (visible on the trader's profile) is the most reliable signal of a consistently improving trader. A sudden score spike on `"low"` confidence often means the trader has few trades recorded — treat it with caution until more history accumulates.
</Tip>

## Companion Endpoint: Daily PnL History

Score history tracks the evolution of a trader's Arcadia Score over time. For raw daily profit-and-loss data, use the companion endpoint:

```
GET https://api.arcadia.trade/v1/traders/:handle/pnl-history
```

This endpoint returns an array of `DailyPnL` objects, each with a `date` (ISO 8601 date string, e.g. `"2024-06-03"`) and a `pnl` field (that day's net profit or loss in USDC, 6 decimal places). Use `pnl-history` to build bar charts of daily returns or calculate rolling drawdown windows independently of the Arcadia Score.
